- QAP와 TSP 문제는 둘 다 NP-complete입니다.
- 일반적으로 QAP는 TSP보다 더 어렵다고 알려져 있습니다. TSP는 QAP의 special case 이기 때문입니다.
    - 즉, QAP의 instance가 TSP의 instance보다 더 넓고 많습니다.
- 이 프로젝트는 동일한 instance를 가지고 TSP와 QAP의 근사해를 구하는 일반적인 두 방법의 성능을 비교/분석합니다.
    - Genetic Algorithm을 사용하여 근사해를 구합니다.
    - QAP의 성능이 더 안좋을 것으로 예상됩니다.
